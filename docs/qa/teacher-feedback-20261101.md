## 저장 및 권한 경계

- 초안/메모는 해당 브라우저 localStorage에만 저장한다. 마지막 저장 후 7일 이내 복원 가능하고 만료된 값은 읽을 때 정리한다. 브라우저 데이터 삭제 시 사라지며 다른 기기와 동기화되지 않는다는 안내를 표시한다. 브라우저를 실행하지 않아도 7일 후 자동으로 물리 삭제되는 서버 보관 정책을 뜻하지 않는다.
- 손상/과대/만료 데이터는 복원하지 않는다. 저장소 접근·용량 오류는 사용자에게 알리고 현재 입력은 유지한다.
- 서버가 접근 가능한 퀴즈/세션을 반환한 뒤에만 노트를 표시한다. 세션/강의실은 계정·경로가 바뀔 때 작업 공간을 다시 구성한다. 브라우저 저장값으로 권한을 판단하지 않는다.
- 진행률의 분자/분모와 최근 학습은 기존 BE `LearningProgressService` 및 `ClassroomService`가 기준이다. 페이지 이동만으로 학습을 완료 처리하지 않는다.
- 서버 동기화 API, 새 API capability, DB/서버 설정, 기능 활성화, 배포, 실제 사용자 데이터 변경 없음.
